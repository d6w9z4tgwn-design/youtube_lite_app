# ClipNest - Independent Player Edition

`yt-dlp`でYouTubeを検索し、標準ではYouTube公式iframeを使わず、ClipNest独自のHTML5音楽プレーヤーで再生するローカルWebアプリです。

## 独自プレーヤー

画面は動画アプリ型のレイアウトです。PCでは折りたためる左サイドバーと大きな動画カード、スマホでは下部ナビと1列フィードを表示します。上部のトピックボタンは選んだ語で検索します。PCの検索結果は横長リスト、スマホの再生操作はコンパクト表示で、「再生設定」からA-B・ブースト・キュー・追加機能を開けます。音声のみの再生方式は変更していません。

検索結果・おすすめ・履歴・登録チャンネルの動画を選ぶと、`/api/media/<video_id>` が `yt-dlp` で音声ストリームを解決し、ClipNestのlocalhostサーバーからRange対応でブラウザへプロキシします。ブラウザ側はHTML5 `<audio>` で再生します。

現在の独自操作:

- 再生 / 一時停止
- 5秒戻る / 5秒進む
- シーク
- 0.75〜2.0倍速
- 音量
- 1曲リピート
- 再生中の動画に関連する「次の候補」
- YouTubeページを外部ブラウザで開くフォールバック

動画カードや登録チャンネルの丸いアイコンを押すと、チャンネルの説明、登録者数、保存済み動画、公式ページへのリンクをまとめた概要画面を開けます。

この構成では音声が同一オリジンの `/api/media/...` から再生されるため、今後Web Audio APIを追加してEQ、ゲイン、フィルタ、解析などへ拡張しやすくなっています。

## 長時間動画

2.3.5ではブラウザの対応形式を確認し、AAC/M4AまたはWebM/Opusを選択します。再生形式・デコードのエラー時は、未試行の対応形式へ一度切り替えます。

2.3.4ではSafari系ブラウザの終了位置付きRange要求にも分割取得を適用しています。長時間動画で接続が滞留し、読み込みが進まなくなる問題への修正です。

長時間動画の準備には通常より時間がかかる場合があります。ClipNest 2.3.3では、YouTube側の長い音声応答を4MB単位で取得してブラウザへ連続配信します。準備が長引いている状態をプレーヤー内に表示し、通信停止時は期限付き音声URLを更新して2回まで自動再接続します。途中まで再生していた場合は、可能な限り同じ位置から再開します。また、停止した音声接続が残っても検索や画面表示を巻き込まないよう、音声接続数を独立して制限しています。

自動再接続後も読み込めない場合は、プレーヤーの「再読み込み」を押してください。それでも再生できない動画は「YouTubeで開く」を利用できます。

## 注意

「次の候補」はログイン情報・APIキーを使わず、再生中のYouTube動画ページの関連欄を取得します。登録済み・同じチャンネル・同じ検索という理由では加点や補充をしません。元動画の分類が音楽の場合は、関連欄で音楽表示のある動画に限定します。細かなジャンルの一致は保証されず、音楽表示がない動画は関連性があっても除外されます。取得制限・ページの仕様変更時は空表示またはエラーにし、無関係な保存動画で埋めません。「再取得」で再試行できます。取得結果は10分間メモリにキャッシュし、動画との対応は端末内に最大7日保持します。自分のログイン済みYouTubeの候補と同じとは限りません。

YouTubeの公式埋め込みプレーヤーを経由しない再生方式は、YouTube側の仕様変更・アクセス制限によって動作しなくなる可能性があります。また、利用時はYouTubeの利用規約と権利者の条件を確認してください。

## 配布版・公開準備（2.5.0）

Windows `.exe` / macOS `.app` のビルド構成を追加しました。Pythonは配布物に含まれます。まだGitHub上でリリースを公開した状態ではありません。公開手順・対象OS・署名の制限は [RELEASING.md](RELEASING.md)、変更履歴は [CHANGELOG.md](CHANGELOG.md) を参照してください。本体のLICENSEは所有者が選定してから確定します。

配布ZIPを展開し、WindowsはClipNestフォルダ内の`ClipNest.exe`（周囲のファイルも必要）、macOSは`ClipNest.app`を起動します。既定ブラウザで画面が開きます。終了は「設定 → 保存先と終了方法 → ClipNestを終了」。ブラウザを閉じるだけでは終了しません。

初回にDB・設定・必要フォルダを自動作成します。更新時にアプリを置き換えても、次の保存先を消さなければ履歴・登録・アプリ設定は残ります。

| OS | ユーザーデータ保存先 |
| --- | --- |
| Windows | `%LOCALAPPDATA%/ClipNest` |
| macOS | `~/Library/Application Support/ClipNest` |
| Linux（ソース版） | `$XDG_DATA_HOME/ClipNest`、未設定なら`~/.local/share/ClipNest` |

`CLIPNEST_DATA_DIR`で保存先を明示できます。旧ソースの`data/clipnest.sqlite3`は新保存先にDBがない場合だけコピーし、元を残します。旧版を終了してから起動してください。ブラウザ保存のプレイリスト・再生位置・モジュール設定はDBとは別なので、同じブラウザと同じポートを使用してください。

「設定」は既定の再生速度・基本動作の診断・yt-dlp更新・保存先など、共通項目だけを扱います。「動作環境を確認」はyt-dlp、FFmpeg、Node/Denoを確認します。追加機能を使わない人にVOICEVOX・Whisperの導入を要求したり、VOICEVOXへ接続確認したりはしません。外部ソフトの自動インストールは行いません。

追加機能の設定は「機能」で対象を有効にし、その行の「設定を開く」から調整します。動画を選ぶ前でも設定できます。VOICEVOXの接続先・Whisperモデルは「VOICEVOX 吹替」内だけに表示します。既存のポート・モデル設定はそのまま引き継ぎます。

動かなくなったら、設定でyt-dlpのバージョンと依存関係を確認し、「yt-dlpを更新」を実行してください。公式GitHub安定版を取得・SHA-256照合してユーザーデータ内に保存し、アプリ再起動後に切り替えます。問題があれば「元の版に戻す」で管理更新版を無効にします。`YTDLP_PATH`を設定している場合はそちらが優先されます。ClipNest本体の自動更新とは別機能です。

「診断情報を保存」は個人履歴を含まないJSONを保存します。ログは保存先の`logs`に容量制限付きで記録します。診断情報も公開前に内容を確認してください。[セキュリティ・プライバシー](SECURITY.md)

Voice同梱版は起動確認用で、PyAV/FFmpeg等の配布条件の確認が終わるまで公開配布しません。通常版の字幕からのVOICEVOX吹き替えは利用できます。

## マイライブラリ・再生画面

YouTube Data APIキー・ログインなしで利用する追加機能です。コメント・高評価は追加していません。

- カード右上の「⋯」から「後で見る」「プレイリストに保存」「最初から再生」を選べます。ホームでは「興味なし」「このチャンネルをおすすめしない」も利用できます。除外はホームと関連自動再生に反映し、検索・登録一覧は隠しません。
- 「マイライブラリ・後で見る」でリスト作成・名前変更・削除・並べ替え・キュー追加・連続再生を管理します。連続再生は確認後に既存キューを置き換えます。リスト100個、各200動画、キュー連続再生100件までです。
- 音声モードの視聴位置を約5秒ごとと一時停止時に保存し、動画を開くと続きから再生します。冒頭5秒未満・最後の10秒・95%以上再生済みでは冒頭から再生します。ライブは対象外です。カードには視聴済みバーを表示します。
- チャンネルページで読み込み済み動画のタイトル検索・新しい順／古い順／再生回数順を選べます。「チャンネル動画を追加」で公開一覧を24件ずつ最大504件まで取得します。公開情報がない項目の並び順は厳密ではありません。チャンネル全動画の検索や無制限取得ではありません。
- プレーヤーの「再生画面」から、大きな再生表示とサムネイル付き関連動画の画面を開きます。音声モードでは再生・シーク・音量を表示直下にまとめ、「音声設定」で速度・区間リピート・キュー・音声加工を操作できます。既存の操作部品を移動して使用し、音量バーや音声要素を複製しません。閉じる／ミニ表示では元のプレーヤーへ戻します。大きな画面で関連動画へ切り替えた場合は再生画面を維持します。
- 概要・チャプター、字幕、映像モードの制限は折りたたんで整理しています。公開概要・チャプターの取得、字幕／自動字幕の文字表示、字幕・チャプターからの音声シーク、位置付きリンクのコピーに対応します。字幕がない動画は取得できません。VOICEVOXのローカル文字起こし機能とは別です。スマートフォンでは1列の全画面レイアウトになります。
- 「映像を開く」はAPIキー不要の公式プライバシー強化埋め込みです。映像を開くと音声プレーヤーは停止し、音声モードへ戻ると埋め込みは閉じます。ミニ表示・拡大表示が可能で、全画面・画質・字幕は公式プレーヤー側で操作します。埋め込み禁止、年齢・地域等の制限がある場合はYouTubeで開いてください。

**映像モードの制限:** APIを介した埋め込みの再生制御は行っていないため、音声加工・アプリの自動再生キュー・視聴位置保存・字幕ハイライトは映像の時刻と同期しません。映像側の現在位置はアプリから読み取れません。位置付きリンクも音声プレーヤーの位置を使用します。公式アカウント同期・公式と同一の推薦・ネイティブ映像プロキシ／オフライン保存は未実装です。公式埋め込みの仕様は [YouTube Embedded Players](https://developers.google.com/youtube/player_parameters) を参照してください。

マイライブラリ・視聴位置・おすすめ除外は、このブラウザの `localStorage` に保存します。別ブラウザ／別のポートとは共有されず、ブラウザのサイトデータ消去で失われます。ホーム等のSQLiteデータと保存先が異なります。J/K/Lで10秒戻る／再生・停止／10秒進むを操作できます（入力欄・ダイアログ内では無効）。

## 次の動画の自動再生

プレーヤーの「自動再生 ON / OFF」で終了後の連続再生を切り替えられます（設定を保存）。手動追加したキューを先に再生し、キューが空なら現在の動画の関連候補の先頭から選びます。同じセッションで再生済みの動画は関連自動再生から除外し、候補がない・取得できない場合は停止します。登録チャンネルなどで補充しません。動画リピート中は移動せず、候補待ち中にOFF・別動画へ移動・シークした場合も自動移動を取り消します。

## 低速再生の音質（Pitch / Tempo Control）

モジュールを有効にし、「速度変更の方式」で「音質優先：Signalsmith Stretch」を選びます。バージョン3からの既定方式です。旧設定からは初回に音質優先へ移行し、その後の方式選択は保存します。SoundTouchとブラウザ標準も比較用に残しています。

Signalsmith Stretch Web 1.3.2（WASM）の周波数領域処理を使用し、解析窓120ms・処理間隔15msで重ね合わせ、計算を分散します。従来のWSOLAの短い波形を繰り返す質感を避けることを狙った音質優先設定で、全音源で最高の聴感を保証するものではありません。特に0.5倍では打楽器のにじみや声の質感変化が残る場合があります。処理遅延は設定画面に表示します。

再生時刻・シーク・動画の長さは引き続き元のプレイヤーが管理します。ブラウザの音程保持を切り、速度変更による音程変化と指定ピッチを一度のDSPで補正します。速度1倍・ピッチ0では原音をそのまま通します。シーク時は内部音声を破棄します。動画全体のメモリ展開、追加のPythonパッケージ、外部への音声送信は不要です。VOICEVOX吹替には適用されません。Safari系の3倍開始時の無音問題は別の制限で、引き続き2倍以下を推奨します。

更新後はアプリを再起動し、ブラウザを再読み込みしてください。ローカルWASMの実行に必要なCSP設定も更新しています（通常のJavaScript `unsafe-eval` は許可しません）。

検証: `tests/browser_quality_pitch.cjs` は実WASMによる44.1/48/96kHz・0.5/0.65/0.75倍・ピッチ併用の音程、ステレオ、PCM連続性、等倍原音通過を確認します。`QUALITY_PITCH=1 TEMPO_RATE=0.5 PITCH_SEMITONES=0 node tests/browser_seek_audio.cjs` はWebKitのAAC再生とシーク後の実音声を確認します。Playwrightの場所は `PLAYWRIGHT_PATH`、テスト先は `CLIPNEST_URL` で指定できます。合成音の自動テストは主観的な音質評価の代わりではありません。

方式の仕様: [Signalsmith Stretch公式ドキュメント](https://github.com/Signalsmith-Audio/signalsmith-stretch/tree/main/web/release)。ライセンスは `THIRD_PARTY_NOTICES.md` を参照してください。

検証上の既知事項: `WEBKIT=1 node tests/browser_modules.cjs` のWAVフィクスチャでは、キュー移動後に全モジュールをOFFにしたあとの時刻進行チェックが失敗します。Signalsmithを使わない旧SoundTouchのみの対照試験でも再現しました。今回のAACシーク試験とは別で、未解決です。

## VOICEVOX 吹替（字幕なしにも対応）

「機能」で「VOICEVOX 吹替」を有効にし、その行の「設定を開く」を押します。同じ端末でVOICEVOXエンジンを起動し、「話者一覧を取得」で接続を確認して声を選択してください。通常は接続先の変更は不要です。別のポートで起動している場合だけ「詳細：VOICEVOXの接続先」を開きます（初期値は`127.0.0.1:50021`）。YouTube APIキーは不要です。

Whisperモデルの選択・動作環境チェック・モデル取得の許可・手動の文字起こしは「字幕がない場合：文字起こし」にまとめています。字幕を取得できればWhisperは不要です。設定を保存するだけではモデルをダウンロードしません。接続先・モデルを変更すると進行中の吹替と文字起こしを停止し、新しい設定で準備し直せます。通常配布版で音声認識が未搭載の場合はその旨を表示し、未公開のVoice試験版を導入するようには案内しません。

**字幕・音声ファイルの準備は不要です。** 「この動画から吹替を準備（ファイル不要）」で字幕を自動取得し、取得できない場合は動画の音声を自動取得してローカル文字起こしへ進みます。SRT/VTTの読み込みは任意の補助機能です。VOICEVOXと、字幕なし用の音声認識パッケージ・モデルの初回準備は必要です。

- 字幕がある動画：「この動画の字幕を取得」、またはSRT/VTTファイルを読み込みます。
- 字幕がない動画：通常配布版には文字起こし機能を同梱していません。開発者向けソース版ではアプリと同じPython環境で `python -m pip install -r requirements-voice.txt` を実行し、ffmpegを導入します。「字幕なし：現在位置から5分を文字起こし」で音声を認識します。初回のみモデル取得の許可チェックが必要です（既に取得済みなら不要）。
- 準備後、「吹替を開始」を押して動画を再生します。生成が間に合わなければ一時停止し、準備完了後に手動で再生を再開します。

文字起こしはfaster-whisperのモデル（既定base、設定でtiny/base/smallを選択）をCPUでローカル実行し、モデルはユーザーデータ保存先の `asr_models` に保存します。音声をクラウド認識サービスへ送信しません。モデルの初回取得にはインターネット接続が必要です。1回の対象は現在位置から最大5分で、長い動画は必要な位置で繰り返してください。認識結果と合成音声は一時的なデータで、再起動後の復元はしません。文字起こしは中止でき、動画変更時にも中止します。認識は数分以上かかる場合があり、誤認識・歌や重なった発話の取りこぼしがあります。

これは文字から作る吹替で、声のクローンや音声分離ではありません。**元の声だけでなくBGM・効果音もミュートされます。** 認識・字幕のない区間は無音になります。吹替音声は元音声のEQ・Pitch処理の対象外です。翻訳・話者ごとの自動振り分け・動画書き出しは未対応です。各VOICEVOX話者と元動画の利用条件、公開時のクレジット条件を確認してください。

参考：[VOICEVOX Engine](https://github.com/VOICEVOX/voicevox_engine)、[faster-whisper](https://github.com/SYSTRAN/faster-whisper)、[SoundTouchJS](https://github.com/cutterbl/SoundTouchJS)。

## 主要API

- `POST /api/search` : YouTube検索
- `GET /api/suggestions?q=...` : ローカル検索候補
- `GET /api/media/<video_id>` : 独自プレーヤー用の音声プロキシ
- `POST /api/history/open` : 視聴履歴記録
- `GET /api/home?offset=0` : おすすめ（48件ずつ、`hasMore` / `nextOffset`で追加取得）
- `GET /api/history` : 履歴
- `GET /api/channel?channelId=...` : チャンネル概要と公開動画
- `GET /api/next?videoId=...` : YouTube動画ページの関連候補（登録チャンネル優先・同チャンネル優先は廃止）
- `GET /api/subscriptions` : 登録チャンネル
- `POST /api/subscriptions/set` : 登録・解除
- `POST /api/subscriptions/refresh` : 新着更新

## データ

履歴・検索傾向・登録チャンネルは、上記ユーザーデータ保存先の `clipnest.sqlite3` に保存されます。旧 `data/clipnest.sqlite3` は移行元としてのみ使用します。

## Safariで再生時間が約2倍になる場合

動画情報とブラウザーが認識した音声時間に大きな差がある場合は、表示だけを補正せず別形式で読み直します。SafariはWebMで音声加工が効かない問題もあるため、ffmpegでAAC音声を再圧縮せず通常のMP4構造へ詰め直す `m4a-safe` を使います。ほかのブラウザーはWebMを代替候補にします。再生速度や秒数の倍率は変更しません。「状態」の「再生・シーク診断」で使用形式と理由を確認できます。

Safariの互換AACにはffmpegが必要です。初回は音声全体を取得するため長時間動画ほど待ち時間が増えます。1ファイル256MB、ダウンロード約180秒＋再構成90秒を上限とし、一時キャッシュは最大2件です。正常終了時に一時ファイルを削除します。上限を超える動画はChromeでお試しください。元データやライブラリーは変更しません。

Safariで音声加工と互換AACを使用しているときは、シーク確定時に同じキャッシュ音声を再ロードしてから指定位置へ移動します。移動前のデコード済み音声とPitch内部バッファを破棄し、ピッチ設定・再生速度・一時停止状態は保持します。通常のシークより短い待ち時間が増えます。`tests/browser_seek_audio.cjs` はWebKitで実際のシーク後の周波数と＋12半音の維持を確認します（ffmpegとPlaywrightが必要）。

## おすすめの地域・言語


ホームの「地域・言語の設定」で国・地域と言語を個別に選択できます。初期状態は指定なしです。「設定を保存」は既存候補の順位に反映し、「保存して候補を補充」は最近のキーワード検索と地域・言語名を組み合わせて yt-dlp で候補を取得します。検索履歴がない場合は地域・言語名のみを使用します。

地域候補の加点は取得から7日間。登録チャンネル・視聴・検索の関連性、視聴済みの減点、チャンネルの偏りを抑える処理と併用します。補充処理は検索履歴や視聴履歴を増やしません。設定はSQLiteに保存され、同じアプリを利用するブラウザー間で共有されます。取得失敗でも設定と既存候補は残ります。

位置情報・IPによる国の推定・YouTubeへのログイン・APIキーは不要です。補充する検索語はYouTubeへ送信されます。これは地域名・言語名を検索ヒントにする方式で、YouTube公式の地域別おすすめやトレンドの再現、動画の国籍・言語の厳密な判定ではありません。

## プレーヤーモジュール

A-Bリピート・音量・Playback Queueは標準プレーヤーに統合しました。音量は0〜300%のバー1本で調整し、100%超だけ「ブースト」と表示します。独立したブースト用バーはありません。100%超は音割れや大きな音に注意してください。追加機能をすべてOFFにしても利用でき、保存済みのキューと音量設定は引き継ぎます。旧ブースト設定は初回に従来の通常音量80%との積で移行し、以降は統合音量を保存します。右上の「機能」には残り10モジュールを表示します。

Voice Enhancer・Stereo Width・Smart Speed・Loudness Meter・Headphone Crossfeedは削除しました。復元用ソースは `archive/removed_modules/` に保管し、アプリからは読み込みません。Audio Labも削除済み機能を呼ばない構成に更新しました。

検索は最大36件、ホームは初回48件、次の候補は最大12件です。ホームは末尾が画面下端の約1,400px先に入ると、保存済み候補を48件ずつ先読みして追加します。追加表示は重複を除外し、取得失敗時はボタンで再試行できます。別画面へ移動した後の応答は混ぜません。保存候補（最大1,200件）が尽きたら追加は終了します。YouTubeから無制限に新規取得する機能ではありません。

検索はYouTubeの関連度順を維持して動画IDの重複を除去します。ホームは直近14日の検索への関心と視聴傾向を優先し、登録だけによる加点を55点から5点へ下げました。地域・言語の加点、古い視聴の影響軽減、チャンネルの分散は維持します。候補の蓄積が少ない場合や取得制限時は上限未満になります。個人にとっての精度向上は実際の利用での確認が必要です。

追加機能は画面右上の「機能」から有効・無効を切り替え、その行の「設定を開く」で調整できます。音声エフェクトの変更は再生中にも反映されます。吹替の声・接続先・モデルなど、再準備が必要な変更は各画面に案内を表示します。

開発者向け：ソース版では `static/modules/*.js` を追加して機能を拡張できます。配布アプリの中身を書き換える手順を一般ユーザーに要求するものではありません。

同梱例:

- 左右バランス
- 5種類のイコライザープリセット
- 音量の均一化
- スリープタイマー

モジュール作成方法と利用できるAPIの詳細は `README_MODULES.md` を参照してください。
